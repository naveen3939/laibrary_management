# Library Management System

A simple **Library Management System** developed in **C** using a **singly linked list**.

## Features

* Add new book
* Update book details
* Remove book
* Search book
* View all books
* Save book records
* Read saved records

> Issue, Return, and List Issued Books are currently under development.

## Technologies

* C Programming
* GCC Compiler
* Singly Linked List
* File Handling

## Compile & Run

```bash
gcc *.c -o library
```

**Windows:**

```bash
library.exe
```

**Linux/macOS:**

```bash
./library
```

## Concepts Used

Structures • Pointers • Linked Lists • Functions • File Handling • Dynamic Memory • Modular Programming
